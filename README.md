# KēRN — калькулятор маржи

Локальное мини-приложение для расчёта маржи по тексту продажи или одному/нескольким счетам в PDF.

При пакетной загрузке каждый PDF рассчитывается отдельно, после чего приложение формирует единую текстовую сводку по всем счетам.

Поле «Логистика» принимает общую сумму затрат и распределяет её между партнёрами пропорционально количеству проданных единиц. Логистика вычитается после расчёта 7% для безнала; округление сохраняет точную общую сумму затрат.

## Запуск

Дважды щёлкните `START_KERN.cmd`. Откроется браузер по адресу `http://127.0.0.1:8765`. Для запуска нужен установленный Python (на текущем компьютере он уже есть).

## Правила расчёта

- Маржа позиции: `(цена продажи − цена отгрузки БАСА) × количество`.
- Отрицательная маржа учитывается как `0 ₽`, фактический минус показывается в отчёте.
- Для безнала вычитается 7% от маржи.
- Наличный счёт определяется по префиксу `0`, латинской `O` или русской `О` в номере счёта.
- Все суммы округляются до целого рубля.

При ручном вводе способ оплаты указывается рядом с каждым партнёром: `Иван (нал):` или `Сергей (безнал):`. Также поддерживается запись через тире: `Иван — нал:`.

Матрица БАСА хранится локально в `dist/catalog.js`. PDF и введённые данные никуда не отправляются.

## Обновление матрицы

Текущий снимок: Google Sheets, лист `ПАРТНЕРЫ`, колонка G, от 31.10.2026. При изменении цен файл `dist/catalog.js` нужно обновить.
